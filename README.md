## 📌 Proyectos destacados

- **DomiiYa** – Plataforma de domicilios para Puerto Boyacá, compuesta por tres apps (cliente, restaurante, conductor) desarrolladas en Flutter. Uso de Firebase para autenticación y base de datos, y lógica de pedidos en tiempo real.

- **Panel Administrativo DomiiYa** – Backend basado en Laravel. Gestión de usuarios, productos, pedidos, y reportes. Se integraron roles y permisos para control administrativo.

- **Sistema de ETL para Contratación** – Scripts en Python y consultas SQL para extracción, transformación y carga de datos desde diferentes fuentes. Generación de reportes y visualización con herramientas como Power BI y Google Sheets.

- **Sistema PAA (Plan Anual de Adquisiciones) – Alcaldía de Puerto Boyacá** – Desarrollo de un módulo web en Laravel para la gestión del Plan Anual de Adquisiciones (PAA), con enfoque en la transparencia y trazabilidad del proceso contractual municipal. Funcionalidades clave:
  - Módulo de administración para registrar, editar y eliminar procesos de adquisición.
  - Clasificación de adquisiciones por tipología, dependencia, estado y presupuesto asignado.
  - Visualización dinámica de los procesos mediante filtros por vigencia, dependencia o tipo de contratación.
  - Exportación de reportes en formatos Excel para control interno y rendición de cuentas.
  - Validación de campos y control de integridad de la información registrada.
  - Diseño responsivo para acceso desde dispositivos móviles y de escritorio.
  - Panel de control para supervisores con métricas resumidas de ejecución presupuestal.
  - Cumplimiento de lineamientos institucionales de uso de tecnologías libres, entrega de documentación técnica, y despliegue en ambiente de pruebas para revisión y aprobación.

- **Sistema de Reclamos – IGAC / Secretaría de Hacienda de Puerto Boyacá** – Desarrollo de un aplicativo web en Laravel orientado a la ciudadanía para la gestión de reclamos catastrales. El sistema está alineado con los estándares del IGAC y la normativa local, con los siguientes componentes:
  - Consulta pública de predios y presentación de reclamos catastrales.
  - Gestión de usuarios con roles diferenciados: ciudadanos, administradores y supervisores.
  - Integración con el portal tributario para el pago del impuesto predial.
  - Carga y administración de documentos de soporte para cada reclamo.
  - Visualización de estadísticas y métricas del sistema en tiempo real para uso administrativo.
  - Módulo administrativo para gestión de reclamos, respuestas, reportes y configuración del sistema.
  - Implementación de medidas de seguridad para protección de datos personales y confidencialidad.
  - Capacitación a los funcionarios encargados y entrega de documentación técnica completa.
  - Mantenimiento y soporte post-entrega, así como cumplimiento de pruebas unitarias, funcionales e integradas.
  - Entrega de derechos de autor y propiedad intelectual a la Secretaría de Hacienda, asegurando la soberanía tecnológica del sistema.


- **Dashboard para CRC – UNAD** – Desarrollo de una plataforma web en Laravel para la Comisión de Regulación de Comunicaciones (CRC), en colaboración con la UNAD. El sistema permite la visualización, análisis y recomendación del uso del espectro radioeléctrico, con los siguientes componentes:
  - Validación de usuarios y control de acceso por roles.
  - Visualización gráfica de niveles de señal, interferencia y cobertura en mapas, usando variables como latitud, longitud, potencia y cobertura.
  - Paneles emergentes con recomendaciones automatizadas sobre el uso adecuado de frecuencias.
  - Módulo de selección y filtrado de datos para simular la afectación en cobertura según parámetros definidos.
  - Importación de datos desde XIRIO y otros repositorios de datos abiertos.
  - Desarrollo de un modelo básico de analítica de datos con reglas proporcionadas por la entidad contratante.
  - Cumplimiento de requisitos no funcionales como: uso de tecnologías libres, pruebas funcionales y automatizadas, despliegue en entorno de pruebas, y entrega de código fuente, documentación técnica y acta de conformidad.

- **Sistema de Gestión Deportiva – Fedetiro** – Desarrollo de módulos funcionales para la plataforma de la Federación Colombiana de Tiro y Caza Deportiva, enfocados en la gestión interna de deportistas, competencias y clubes afiliados. Funcionalidades principales:
  - Registro y administración de usuarios con distintos roles: atletas, entrenadores, clubes, y administradores federativos.
  - Gestión de competencias nacionales e internacionales, incluyendo inscripciones, programación de eventos y resultados.
  - Módulo de control de membresías y licencias deportivas, con validación por vigencia y categoría.
  - Generación de reportes administrativos sobre participación, resultados y evolución de atletas.
  - Paneles informativos para consulta pública de eventos y rankings.
  - Cumplimiento de lineamientos de seguridad de datos personales y políticas institucionales de la Federación.
  - Diseño responsivo para facilitar el uso desde dispositivos móviles durante competencias en campo.
  - Entrega del sistema funcional, documentación técnica y sesiones de capacitación para el personal de la Federación.
